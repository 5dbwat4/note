# Excalidraw

Embed an [Excalidraw](https://excalidraw.com) board. The component accepts
either an inline `payload` or a `src` URL pointing at a `.excalidraw` / JSON
file. `payload` wins when both are supplied.

The board is transparent by default (set `appState.viewBackgroundColor` to
override), view-only with the top toolbar hidden (`hideToolbar={false}` keeps
it), and automatically zoomed to fit its content with `padding` (default
`40`) px of breathing room.

## Inline payload

<Excalidraw payload={payload} height="360px" />

```mdx
<Excalidraw payload={payload} height="360px" />
```

## Loaded from src

The diagram file is imported as a URL with Vite's `?url` suffix, so no
`public/` directory is needed:

```mdx
import diagramUrl from "./example.excalidraw?url";

<Excalidraw src={diagramUrl} height="420px" />
```

<Excalidraw src={diagramUrl} height="420px" />

## View only

Boards are view-only by default (`viewMode` defaults to `true`):

<Excalidraw src={diagramUrl} height="420px" />

```mdx
<Excalidraw src={diagramUrl} height="420px" />
```

## Editable

<Excalidraw src={diagramUrl} height="420px" viewMode={false} />

```mdx
<Excalidraw src={diagramUrl} height="420px" viewMode={false} />
```

## More padding when fitting

<Excalidraw src={diagramUrl} height="420px" padding={96} />
